# Платформа

Android-приложение клуба: абонемент, расписание, тарифы, баланс и магазин. Kotlin + Jetpack Compose, Android 8.0+.

## Запуск
Откройте папку в Android Studio, выполните Gradle Sync и запустите app. Android SDK 35, Gradle 8.9, JDK 17 или 21.

Общие контакты: data/ClubContacts.kt. Для посещения предъявите карту на ресепшене. Сведения об абонементе доступны в профиле и на главной.

## Добавление товаров
1. В профиле включите демонстрационный режим администратора.
2. Откройте «Магазин», нажмите плюс справа вверху.
3. Введите название, описание, категорию, цену (необязательно) и доступность.
4. Сохраните. На карточках доступны изменение и удаление с подтверждением.

Покупка и получение — на ресепшене. Стартовые товары являются примерами: клуб должен подтвердить ассортимент и цены.
Каталог сохраняется на устройстве между запусками, включая пустой список. Синхронизации между телефонами пока нет. Для общего каталога нужен сервер с проверкой прав сотрудников; точка подключения — ShopRepository. Локальный переключатель администратора предназначен только для демонстрации.

## Структура
- data/model — модели клиента, абонемента и занятий.
- data/remote — интерфейс CRM и заглушка.
- data/repository — сессия, расписание, каталог.
- ui/shop — витрина и редактор товаров.
- ui/components/Brand.kt — знак из девяти плиток.
- ui/navigation — маршруты и нижнее меню.
